**Abstract:**

NoteNest: Text Editor Core implements the data-structure engine behind every editor and notes app: word counts, find, autocorrect and bracket matching. The project is built as six milestones, each using a technique from its week of the course: hash-based word counting for the most used word (O(n)), dynamic programming for autocorrect edit distance (O(nm)), prefix sums for words-in-paragraph range queries (O(n + q)), KMP string search for Find All (O(n + m)), binary search on cumulative line ends for jumping to a character offset (O(log n)), and a stack for bracket matching (O(n)). Every milestone is written in Java, checked against its worked example and our own edge cases from a single main, and compared with a brute-force version using operation counts on growing inputs generated by the course's linear congruential generator.
